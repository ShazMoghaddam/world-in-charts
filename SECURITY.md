# Security policy

World in Charts is data and static images, with one build script. The main risk would be data that ends up running as script or markup in a chart.

## Reporting a vulnerability

Please report it privately, not in a public issue.

1. Open the [Security tab](https://github.com/ShazMoghaddam/world-in-charts/security) and press **Report a vulnerability**, or go straight to [a new advisory](https://github.com/ShazMoghaddam/world-in-charts/security/advisories/new).
2. Describe the problem and the steps that show it.

You'll get a reply within 7 days. Once the problem is confirmed, I'll agree a fix and a disclosure date with you, and credit you in the changelog unless you'd rather stay anonymous.

## Scope

In scope: the data files, the build script and the charts it produces.

Out of scope: problems in Bezel Charts itself, which belong in [its own security policy](https://github.com/ShazMoghaddam/bezel-charts/security), and third-party services such as npm.

A wrong fact isn't a security issue. Please open a normal issue for those.
